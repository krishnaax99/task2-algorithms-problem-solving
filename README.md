# Task 2 - Algorithms & Problem Solving (C++)

## Overview
This project demonstrates algorithm implementation in C++.

Implemented Algorithms:

1. Merge Sort (Sorting)
2. Binary Search (Searching)
3. 0/1 Knapsack (Dynamic Programming)

## Time Complexity

### Merge Sort
- O(n log n)

### Binary Search
- O(log n)

### Knapsack
- O(n * W)

## Features
- Sorting algorithm implementation
- Searching algorithm implementation
- Dynamic programming problem
- Runtime measurement included
- Test cases included

## How to Run

### Compile
```bash
g++ main.cpp -o app
```

### Run
```bash
./app
```

## Sample Test Cases

1 3 4 7 9 12 15
